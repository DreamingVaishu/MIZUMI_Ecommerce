# 🛍️ Mizumi eCommerce

Mizumi eCommerce is a modern and responsive eCommerce web application built to provide a seamless shopping experience. It features product listings, cart management, and a smooth checkout flow with a clean UI.

## 🚀 Features
- Beautiful and responsive design  
- Browse and search products easily  
- Add to cart and manage items  
- Smooth checkout experience
