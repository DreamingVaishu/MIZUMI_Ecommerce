# 🛍️ Mizumi eCommerce

Welcome to **Mizumi eCommerce** — a modern, responsive, and stylish online shopping platform built with cutting-edge web technologies.  
Enjoy smooth browsing, cart management, and a delightful checkout experience!

---

## ✨ Features
- 📱 **Responsive Design** — Works seamlessly on desktop and mobile.  
- 🛒 **Smart Cart System** — Add, remove, and manage items with ease.  
- 🔍 **Product Browsing & Search** — Quickly find what you need.  
- ⚡ **Fast & Optimized** — Built with Vite + React for speed.
